Midterm Examination Reflection:

1. What is Git used for?

Git is used for tracking changes and managing the version history of programming projects. It lets developers save progress, compare different versions, and restore earlier iterations of files.



2. What is the difference between Git and GitHub?

Git is a local version control system, while GitHub is a cloud-hosted service for storing Git repositories and facilitating online collaboration. GitHub adds remote hosting, issue tracking, and sharing features on top of Git.



3. Why is branching useful?

Branching is useful because it allows working on different parts of the system simultaneously. It keeps development isolated on their branches and makes it safer to merge changes later.



4. What command did you use to upload your local commits to GitHub?

I used 'git push origin main' to upload local commits to GitHub. That command sends the committed changes from the local main branch to the remote repository.



5. What did you learn from this activity?

I learned how to organize project work and separate changes from the main repo by utilizing branches. I also practiced the workflow of committing, switching branches, and preparing merge changes.
